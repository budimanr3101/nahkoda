---
title: Filosofi Bahasa
description: Mengapa dan bagaimana Nahkoda menggunakan Bahasa Indonesia.
---

Nahkoda berpegang teguh pada filosofi **"Bahasa manusia untuk Kubernetes"**.

### Kosakata Nautical

Kami menggunakan metafora pelayaran untuk memetakan konsep Kubernetes yang kompleks menjadi lebih intuitif:

- **Kapal** = Cluster / Context
- **Geladak** (Deck) = Namespace
- **Kru** = Pod
- **Mesin** = Node
- **Jurnal** = Logs
- **Berita** = Events

### Konsistensi Pesan

Bukan hanya perintah, semua interaksi dalam Nahkoda menggunakan Bahasa Indonesia:
- Pesan Bantuan (`--help`)
- Pesan Kesalahan (Error Messages)
- Tips dan Saran
- Status Eksekusi

:::tip
Tujuan utama kami adalah membuat pengelolaan infrastruktur terasa lebih dekat dan tidak mengintimidasi bagi pengembang di Indonesia.
:::
