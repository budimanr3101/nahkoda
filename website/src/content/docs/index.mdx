## Kenapa Nahkoda?

Nahkoda bukan pengganti `kubectl`, tapi "penerjemah" agar perintah lebih mudah diingat dengan analogi pelayaran yang intuitif.

<CardGrid>
	<Card title="Bahasa Manusia" icon="pencil">
		Gunakan perintah seperti `liat kru rusak` daripada menghafal flag kubectl yang panjang.
	</Card>
	<Card title="Sangat Ringan" icon="rocket">
		Ditulis dalam Pure Go tanpa dependensi berat. Binary hanya ~2.9MB.
	</Card>
	<Card title="Toleransi Typo" icon="magnifier">
		Kapten lelah? Nahkoda paham typo seperti `kur` dan akan menyarankan `kru`.
	</Card>
	<Card title="Multi-Platform" icon="setting">
		Dukungan penuh untuk macOS, Linux, dan Windows via Brew & Scoop.
	</Card>
</CardGrid>
